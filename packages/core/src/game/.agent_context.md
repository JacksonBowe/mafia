Game domain package.

- `index.ts`: server-side game operations, realtime events, voting/trial helpers, and Step Functions phase advancement.
- `schema.ts`: pure shared game schemas/types exported through SDK-safe contracts.
- `chat.ts`: pure game chat send/subscription policy helpers shared by backend and frontend.
- `game.sql.ts`: Drizzle tables for games and game players, including stored Step Functions game loop execution ARN.

`advancePhase` is backend loop authority. It emits `PhaseChange` after commit where `duration` means seconds for the phase being entered. `terminate` deletes game records and stops the stored Step Functions execution after commit.

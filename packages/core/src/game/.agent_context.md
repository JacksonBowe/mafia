Game domain package.

- `index.ts`: public barrel; exports `Game`, server-domain named exports, and shared schema/type contracts.
- `game.ts`: server-only game record create/read/list/termination operations; exposes `Game.Session`.
- `schema.ts`: pure game-record `GameErrors`, status, and summary `GameInfo` contracts; barrel for session contracts.
- `session/`: active-game behavior, contracts, events, chat policy, and audit logging.
- `game.sql.ts`: Drizzle tables for games, players, idempotent phase commands, append-only game audit logs, and engine diagnostics.

`Game.get`/`Game.list` return game-record summaries. `Game.Session.get` returns full persisted `GameSessionInfo`, including completed/cancelled sessions. `Game.Session.Phase.advancePhase` is backend loop authority. It serializes expected-version/idempotency-key commands, emits `PhaseChange` after commit where `duration` means seconds for the phase being entered. `Game.terminate` marks a game cancelled, stops the stored Step Functions execution, and emits `Terminated` after commit; records remain for review.

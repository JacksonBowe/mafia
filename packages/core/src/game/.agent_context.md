Game domain package.

- `index.ts`: server-side game operations, realtime events, voting/trial helpers, and Step Functions phase advancement.
- `schema.ts`: pure shared game schemas/types exported through SDK-safe contracts.
- `chat.ts`: pure game chat send/subscription policy helpers shared by backend and frontend.
- `game.sql.ts`: Drizzle tables for games, players, append-only game audit logs, and engine diagnostics.
- `log.ts`: server-only GameLog/EngineLog contracts and transactional append helpers.

`advancePhase` is backend loop authority. It emits `PhaseChange` after commit where `duration` means seconds for the phase being entered. `terminate` marks a game cancelled, stops the stored Step Functions execution, and emits `Terminated` after commit; records remain for review.

Game domain package.

- `index.ts`: server-side game operations, realtime events, voting/trial helpers, and Step Functions phase advancement.
- `schema.ts`: pure shared game schemas/types exported through SDK-safe contracts.
- `game.sql.ts`: Drizzle tables for games and game players.

`advancePhase` is backend loop authority. It emits `PhaseChange` after commit where `duration` means seconds for the phase being entered.

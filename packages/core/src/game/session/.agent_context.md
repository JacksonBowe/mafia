Active game-session domain.

- `index.ts`: `Game.Session` facade; re-exports operations and focused namespaces.
- `state.ts`: full session reads, sync payloads, engine state, target, event, and loop execution updates.
- `vote.ts`: poll vote operations.
- `verdict.ts`: verdict, trial, and poll-count operations.
- `phase.ts`: authoritative phase-advance loop and transition helpers.
- `events.ts`: server-only realtime events; future EventBus events belong here.
- `chat.ts`: pure chat send/subscription policy helpers shared by backend and frontend.
- `log.ts`: server-only game/engine audit contracts and transactional append helpers.
- `schema.ts`: pure `GameSessionErrors`, full `GameSessionInfo`, phase, player, sync, topic, and engine contracts.

No session table exists: `Game.Session` organizes active-match behavior around existing game tables.

# packages/scripts

Reusable one-shot scripts. Run each via `sst shell` so SST `Resource` bindings
(DB url, etc.) are injected.

## Files

| Path                | Purpose                                                                                                                                   |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `src/createBots.ts` | Wipe all `is_bot` users, recreate 14 bots + 1 API key each. Prints raw keys JSON or writes with `--out`. |

## Commands

```bash
bun run create-bots                      # prints bots.local.json to stdout
bun run create-bots > ../bots/bots.local.json
bun run create-bots:prod                 # writes ../bots/bots.prod.json against prod stage
```

## Notes

- Only key hashes are stored in the DB (`user_api_key.key_hash`); the raw keys
  printed by `create-bots` are the only copy — capture them.
- STDOUT is pure JSON; progress logs go to STDERR so output is pipeable.
- User runs all DB actions; `user_api_key` table must be migrated first.

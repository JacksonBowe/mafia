Engine package source.

- `index.ts`: public engine entrypoints (`newGame`, `loadGame`, `resolveGame`, `lynchGame`) and exports.
- `game.ts`: mutable in-memory game model used by entrypoints.
- `events.ts`: engine event tree and duration helpers.
- `roles/`: role implementations and actor state schema.
- `types.ts`: engine input/result/state/config schemas.

Prefer adding lifecycle behavior through public entrypoints in `index.ts` instead of exposing engine internals.
